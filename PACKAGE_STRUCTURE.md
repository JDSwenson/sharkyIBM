# sharkyIBM Package Structure

## Summary

The sharkyIBM package is organized as a standard R package with clear separation between:
- **Package code** (what gets installed)
- **Documentation** (roxygen2-generated .Rd files and package-level docs)
- **Development notes** (memory files, roadmaps, conversation exports)
- **Tests** (testthat unit tests)

## Directory Layout

```
sharkyIBM/
├── R/                          # Main package source code
│   ├── create_stable_pop.R    # Calibrate population parameters
│   ├── simulate_population.R  # Run IBM simulation
│   ├── sample_pop.R           # Apply hierarchical sampling
│   └── globals.R              # Global variable definitions
│
├── man/                        # Roxygen2-generated documentation
│   ├── create.stable.pop.Rd
│   ├── sample.pop.Rd
│   ├── simulate.pop.Rd
│   └── figures/
│
├── inst/                       # Installation directory
│   ├── CITATION               # Package-level citations
│   └── REFERENCES.bib         # BibTeX bibliography
│
├── tests/                      # Unit tests (testthat)
│   ├── testthat.R
│   └── testthat/
│
├── docs/                       # Development documentation (excluded from build)
│   ├── AGENTS.md              # Project memory & design decisions
│   ├── CITATION_GUIDE.md      # Citation maintenance guide
│   ├── DOCUMENTATION_*.md     # Documentation roadmaps & completion logs
│   ├── SPECIES_GENERALIZATION_TODO.md
│   ├── conversation-export.{html,md}

├── DESCRIPTION                # Package metadata

├── .Rbuildignore             # Build ignore rules

```

## File Purposes

### Source Code (R/)

| File | Purpose |
|------|---------|
| `create_stable_pop.R` | Stabilize populations via s0 calibration or DD conception adjustment |
| `simulate_population.R` | Forward-time IBM with Markov breeding, density dependence, parentage tracking |
| `sample_pop.R` | Hierarchical sampling with trip/set structure and social reshuffling |
| `globals.R` | Global variable definitions (required by R CMD check) |

### Documentation (man/)

Auto-generated from roxygen2 `@` tags in R source files. Do not edit directly.

### Installation (inst/)

- **CITATION** — Metadata for `citation("sharkyIBM")`
- **REFERENCES.bib** — BibTeX database linked from function `@references` tags

### Development (docs/)

**Excluded from package build** (via `.Rbuildignore`). Contains:

- **AGENTS.md** — Project memory: design principles, parameter specs, test results, implementation status
- **CITATION_GUIDE.md** — How to maintain and update citations
- **Documentation roadmaps** — Maps of parameter documentation across functions
- **Species generalization roadmap** — Plans for extending to other species
- **Conversation exports** — Large chat history exports (non-essential)

### Configuration Files

| File | Purpose |
|------|---------|
| `.gitignore` | Git ignore rules (IDE files, build artifacts, dev logs) |
| `.Rbuildignore` | R build system ignore rules (excludes docs/ from package) |
| `DESCRIPTION` | Package metadata (version, dependencies, authors) |
| `NAMESPACE` | Specifies exports and imports (generated by roxygen2) |
| `sharkyIBM.Rproj` | RStudio project settings |

## Build & Check

Standard R package commands:

```r
# Install development version
devtools::install()

# Check package integrity
devtools::check()          # 0 errors, 0 warnings, 0 notes (clean)

# Build documentation
devtools::document()       # Generates .Rd files from roxygen2 comments

# Run tests
devtools::test()           # Runs testthat tests
```

## Git Workflow

### Tracked by Git

- R source code (`R/`)
- Documentation metadata (`inst/`)
- Roxygen2-generated docs (`man/`)
- Tests (`tests/`)
- Configuration files (`.Rbuildignore`, `.gitignore`, `DESCRIPTION`, `NAMESPACE`, etc.)
- README (`README.md`, `README.Rmd`)

### Excluded from Git

Via `.gitignore`:
- RStudio files (`.Rproj.user/`, `.Rhistory`)
- Build artifacts (`*.Rcheck/`, `*.tar.gz`)
- AI assistant local files (`.posit/`, `.claude`, etc.)
- Conversation exports
- IDE files (`.vscode/`, `*.swp`)

Via `.Rbuildignore`:
- Development documentation (`docs/`)
- Development `.md` files (`README.Rmd`, `LICENSE.md`)


**Excluded** from the tarball:
- `docs/` folder
- `.Rbuildignore`
- `.gitignore`
- `README.Rmd`
- `LICENSE.md`
- RStudio project file
- Any untracked development files

## Quick Reference

| Task | How |
|------|-----|
| Add a new function | Create in `R/`, add roxygen2 `@` comments, run `devtools::document()` |
| Update documentation | Edit roxygen2 comments in R source, run `devtools::document()` |
| Add a test | Create in `tests/testthat/test-*.R`, run `devtools::test()` |
| Update citations | Edit `inst/REFERENCES.bib` and function `@references` tags |
| Update memory | Edit `docs/AGENTS.md` or use `/savememory` in Posit Assistant |
| Check package | Run `devtools::check()` |
